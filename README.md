# practice_terrain_classifier
## Техническое задание на разработку классификатора местности по фотографии на основе свёрточной нейронной сети

**Цель проекта:** разработать простой классификатор на основе свёрточной нейронной сети для определения следующих типов локаций на изображениях:  
- City  
- Forest  
- Field  
- Mountains  
- Building  
- Desert  
- Polar region  
- Open waters  

## Требования к классификатору

### Входные данные
Изображения в формате, поддерживаемом стандартными библиотеками обработки изображений (например, JPEG, PNG).

### Выходные данные
Вероятность принадлежности изображения к каждому из классов:
- City  
- Forest  
- Field  
- Mountains  
- Building  
- Desert  
- Polar region  
- Open waters  

### Точность классификации
Не менее 80% на тестовой выборке.

### Скорость работы
Время классификации одного изображения не должно превышать 1 секунды на стандартном компьютере.

### Платформа
Разработка и тестирование классификатора должны быть выполнены на платформе, совместимой с Python.

### Библиотеки
Для разработки классификатора можно использовать:
- TensorFlow  
- Keras  
- PyTorch (в приоритете)
